# 看海 · 慢慢的海边

一个治愈系的网页小游戏：看海、等潮水退去、在沙滩上捡贝壳。
没有目标，没有失败，想待多久就待多久。

在线游玩：<https://xueqing1819.github.io/kanhai/>

## 怎么玩

- 什么都不用做，先看一会儿海
- 潮汐 15 秒一个涨落周期，顶部潮汐条会显示现在是涨潮还是退潮
- 退潮时沙滩上会出现贝壳和海玻璃，点击就能捡起来；涨潮时什么都捡不了，捡剩下的会被海水带走，慢慢等就好
- 物品分常见 / 少见 / 稀有三档，一共 7 种，越少见的越难碰到，稀有物品带微微的光
- 每 4 次退潮会有一次「大退潮」：水退得特别远，露出平时看不见的湿沙带，里面会刷限定物品（珊瑚枝、月光螺），还必出一个漂流瓶
- 潮汐条右侧亮起小星星，就是在预告下一次是大退潮
- 捡到漂流瓶会打开一张纸条，句子都收在图鉴的「句子」页里，一共 24 句
- 退潮时沙滩上偶尔会鼓起一个小沙堆，点它挖挖看：可能挖到少见以上的好东西，可能只是一块乖乖的石头，也可能惊动一只小螃蟹
- 涨潮等着的时候不用干等：海浪偶尔会把一件好东西推上岸，停在那儿等退潮了再去捡
- 天上偶尔有海鸥慢慢飞过；退潮的沙滩上有时会跑过一只小螃蟹，点它附近的沙子，它会慌慌张张钻进沙里躲起来
- 运气好的话，能看到海豚跃出海面划一道弧线，还带着一声落水声，平均要等上八到十分钟
- 海天交界线上常年漂着一两艘白帆船，慢得几乎看不出在动；天黑以后，每艘船会亮起一盏小小的暖黄船灯
- 一个游戏日是现实里的 8 分钟：白天、黄昏、夜晚、黎明慢慢轮流；黄昏看太阳沉下去，夜晚有星星、月亮，还有月光洒在海面上
- 夜晚和黎明更容易遇见月光螺，白天的海玻璃亮闪闪、也更好找
- 图鉴慢慢凑齐套装，海边会悄悄多出一些装饰：一串贝壳风铃、一盏天黑自动亮的小灯、一把岸边的伞
- 图鉴里还有一页「日记」，记着你来了多久、捡了多少小东西、连续来了几天
- 图鉴最后一页是「海边的朋友」：海鸥、螃蟹、海豚各一格，记着遇到过几次；海豚在第一次遇见之前，那一格只会写着「？？？听说海里有大家伙」
- 图鉴、句子和统计自动存在浏览器里，刷新不会丢，第二天来还会跟你打招呼
- 第一次点击屏幕后会有海浪声和背景音乐，右下角小按钮可以静音

电脑和手机横屏都能玩。

## 在本地跑起来

直接双击 `index.html`，用浏览器打开就能玩，不需要安装任何东西。

也可以起个本地服务器：

```bash
python -m http.server 8123
# 然后访问 http://localhost:8123
```

## 改着玩

代码里几个好改的参数，都在 `index.html` 里，搜变量名就能找到：

| 参数 | 默认值 | 作用 |
|---|---|---|
| `TIDE_PERIOD` | 15 | 潮汐一个完整涨落周期的秒数 |
| `LOW_TIDE_LINE` | 0.3 | 潮位低于多少算退潮（能捡东西） |
| `TIDE_PHASE` | -1.159 | 开局时的潮位，改 0 就是从满潮开始 |
| `BIG_TIDE_EVERY` | 4 | 每 4 次退潮出现 1 次大退潮 |
| `BIG_TIDE_LINE` | 0.42 | 大退潮判定线（退潮窗口更长） |
| `BIG_TIDE_LIFT` | 80 | 大退潮比普通退潮多退出多少像素 |
| `DAY_LENGTH` | 480 | 一个游戏日有多长（秒），白天/黄昏/夜晚/黎明四等分 |
| `MOUND_CHANCE` | 0.35 | 每次退潮刷出沙堆的概率（挖开结果 55% 物品 / 30% 石头 / 15% 螃蟹） |
| `DELIVER_CHANCE` | 0.35 | 涨潮期海浪送物品上岸的概率（每 20~40 秒掷一次） |
| `GULL_MIN` / `GULL_SPAN` | 60 / 60 | 海鸥飞过的间隔：60~120 秒一只 |
| `CRAB_WALK_CHANCE` | 0.4 | 退潮时螃蟹横行出场的概率 |
| `DOLPHIN_MIN` / `DOLPHIN_SPAN` | 480 / 120 | 海豚跃出的间隔：平均 8~10 分钟一次 |
| `BGM_VOLUME` | 0.35 | 背景音乐音量 |
| `TYPES` | 7 种 | 物品种类：名字、画法、出现权重、稀有度 |

代码里用大注释标了三个关键部分：潮汐状态、收集逻辑、渲染循环，顺着注释找就能改。

## 技术说明

- 纯原生 HTML/CSS/JavaScript，不用框架，不用外部图片、字体和音频素材（背景音乐除外）
- 海面是 Canvas 画的正弦波叠加，两层波浪一慢一快，波光是随机出现的小短线
- 画布逻辑分辨率固定 1280x720（16:9），随窗口大小缩放
- 海浪声是 Web Audio API 实时生成的白噪音加低通滤波，不是音频文件；捡到稀有物品的「叮」也是合成的
- 潮位、水线位置、物品出现时间，全都由一个余弦函数驱动
- 图鉴、漂流瓶句子和统计数据存在浏览器 localStorage 里，不联网、不上传
